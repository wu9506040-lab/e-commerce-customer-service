# 演示手册（面试 / 汇报现场用）

> 原则：演示重心放在工程层（可控性），应答层主动交底边界。
> 面试官乱发消息不是风险，是演示「兜底 + 人工接管」的入口。

---

## 0. 演示前 1 分钟体检（demo_check 清单）

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| Docker 六容器 | `docker ps` | api/milvus/mysql/redis/frontend 全 Up，无 Restarting |
| daemon 注册 | 日志尾部或 `xianyu:workers` | `注册完成`，a1 状态 running |
| cookie 有效 | `grep -o "unb=[0-9]*" cookie.txt` 与日志 unb 一致 | unb 存在且 daemon 未报 token 失效 |
| 端到端 | 用测试小号发「在吗」 | 3 秒内收到「在的~」 |
| 工作台 | 打开 `/admin/xianyu` 登录 | 会话列表 61+，最新消息可见 |
| 兜底预案 | 手机里备好录屏视频 | 60s「发问→AI 秒回」录屏可用 |

## 2. 演示动线（8-10 分钟，不重样）

### 2.1 工作台全景（1 min）
打开 `/admin/xianyu`：三栏布局、会话列表（渠道标签/状态标签/未读红点）。
→ 话术：「这是坐席侧，AI 和人工的所有消息实时落库，面试官您看到的每一
条都能追溯到数据库。」

### 2.2 实时消息（2 min）
用测试小号发三组预演过的问题：
- 「在吗」→ 秒回「在的~有什么可以帮您？」
- 「能便宜点吗」→ 议价 Agent 回应
- 「充电宝能带上飞机吗」→ RAG 回复带引用角标 [1]

### 2.3 乱问环节——主动邀请（2 min）
「您随便发。」三种走向都有预案（见 §4）。

### 2.4 人工接管（2 min）
点「接管会话」→ 小号再发消息 → AI 沉默 → 坐席在工作台手打回复 → 小号收到。
→ 话术：「AI 拿不准的全部转人工，消息不丢、上下文保留。」

### 2.5 工单闭环（1.5 min）
小号发「能退款吗」→ 演示自动建 P1 工单（订单证据 + 摘要）→
`/admin/handoff` 认领。

### 2.6 评测报告收尾（0.5 min）
打开 `docs/` 评测报告：双口径 76.7%/75.0%、失败案例分类。
→ 话术：「我知道它哪里不行，这比『感觉它挺聪明』值钱。」

## 3. 高频追问 Q&A（背诵级）

**Q：跟咸鱼自带的机器人有什么区别？**
> 咸鱼官方机器人是平台侧的固定话术，卖家不可定制、看不到会话数据。
> 我这个是卖家侧的：① 知识库是卖家自己喂的（RAG 私有商品知识）；
> ② 有意图路由和策略（议价/退款/售后不同处理）；③ **有坐席侧**——
> 接管、工单、统计，这是官方机器人完全没有的。企业买客服系统买的
> 不是聪明，是可控。

**Q：有多少真实用户？**
> 目前是测试账号在真实渠道上端到端验证，单 SKU 评测双口径 76.7%/75.0%。
> 这个项目的难点在协议栈逆向和应答管线，不在流量规模——真实流量的
> 灰度是我接下来要做的第一步。

**Q：订单/发货闭环呢？**
> 我做到了订单证据识别（会话内交易卡片扫描）、退款校验、自动建单联动；
> 完整的下单-发货闭环依赖闲鱼开放能力，发货自动化是路线图下一步。

**Q：为什么逆向协议，不用官方 API？**
> 闲鱼没有面向个人的客服开放 API——这正是这个项目有工程含量的原因。
> 私有协议 = 无文档 + 有风控 + 会改版，我为此做了 ackDiff 补拉、去重、
> 四层 Cookie 自愈。

## 4. 乱问兜底预案（三种走向）

| 面试官发的消息 | 系统行为 | 你的接话 |
|----------------|----------|----------|
| scope 外问题（"你会写代码吗"） | chitchat/兜底链路，得体但不承诺 | 「scope 外走兜底——这就是为什么企业场景必须有人工接管」→ 现场演示接管 |
| 别的商品（"你们耳机多少钱"） | 未命中知识库，兜底引导 | 「知识库隔离是按渠道和 SKU 做的，上新商品只需入库，不改代码」 |
| 订单操作（"帮我退货"） | 退款流程：查订单证据 → 无单告知 / 有单建工单 | 现场看工单生成 |

**底线**：任何回答不出彩，都接「这正好引出人工接管的价值」——永不冷场。

---

## 5. 翻车预案（按概率排）

1. **服务没起** → 提前 30 分钟到场跑 §0 清单；笔记本不关机睡眠
2. **cookie 过期/风控** → 体检第 3 项会暴露；兜底：切录屏视频
3. **网络故障** → 录屏视频（60s 发问→秒回）永远在手机里
4. **工作台卡顿** → 刷新即可；数据都在 MySQL，不是假数据
